本项目是一个基于大语言模型（LLM）和检索增强生成技术（RAG）构建的文档问答系统。用户通过前端界面上传PDF文档，系统自动进行文本解析、分块、向量化并存入向量数据库。用户随后可针对文档内容提问，系统会精准检索相关上下文，交由大模型进行归纳总结，返回准确、严谨的回答。有效解决了通用大模型在垂直领域知识不足及容易产生“幻觉”的问题
一开始我使用向量检索,发现幻觉抑制效果不是很明显,我更换了检索方式,采用bm25检索和父子文档检索组成的混合检索,bm25检索的比重为0.4,父子文档检索的比重为0.6,bm25适合关键词匹配,父子文档检索"用小块精准定位，用大块完整回答更精准,改良后提问,大模型回答的准确性与专业性有了显著的提升.
